# Contributing to ZeoStudio TenGate

Thank you for helping improve ZeoStudio.

## Before opening an Issue

- Search existing Issues first.
- State the affected architecture: A, B, C, or the TenGate distribution layer.
- Separate observed behavior from assumptions.
- Provide reproducible steps and verifiable evidence when possible.
- Never post credentials, private recovery material, decrypted private archives, or personal data.

## Pull requests

- Keep each pull request focused on one change.
- Explain the problem, the proposed change, and how it was verified.
- Preserve task ownership, review gates, rollback paths, and evidence requirements.
- Do not modify release signatures, manifests, version numbers, or official archives in an unrelated pull request.
- Do not claim certification, guaranteed runtime, or universal security properties without independently verifiable evidence.
